# Ubiquitous Language

Statut : Accepté — index de référence
Version : 2.1
Date : 2026-07-27
Remplace : aucun document ; ne constitue pas un second glossaire

Le langage métier officiel est défini dans l'unique [Glossaire métier](../16-Glossaire-metier.md). Le présent document en précise l'usage architectural sans dupliquer ses définitions.

- **Occupation** désigne exclusivement le blocage générique d'une ressource dans le Calendrier.
- **Réservation**, **Match** et **Entraînement** restent des concepts de leur domaine d'origine.
- **Événement du club**, **événement public** et **événement éditorial** restent des contenus ou activités publiés.
- **Événement de domaine** désigne un fait métier passé, par exemple `ReservationConfirmed`.
- **Personne**, **Compte utilisateur**, **Adhésion** et **Joueur** ont des cycles de vie distincts.
