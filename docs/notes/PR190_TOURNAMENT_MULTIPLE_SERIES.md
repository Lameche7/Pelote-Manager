# PR190 — Un joueur peut participer à plusieurs séries

## Règle métier

Dans un même tournoi PILOTOKI :

- un joueur peut être inscrit dans plusieurs séries différentes ;
- un joueur ne peut pas être inscrit dans deux équipes différentes de la même série.

Exemples autorisés :

- 1re Série + 2me Série ;
- 4me Série + Féminines ;
- série principale + Mixte.

La règle s'applique de manière cohérente à l'import externe, au rapprochement d'identité après import et à la confirmation d'une participation par le joueur.
